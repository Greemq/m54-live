  Настройки
  
  
  
  
  
  
  
Расход «по впрыску» считается из времени открытия форсунок (минус ~1 мс мёртвого времени) при 237 см³/мин. «По ДМРВ» — из воздуха при лямбде 1, на сбросе газа и при обогащении врёт.

  
DTR/RTS переключают режим у некоторых кабелей K+DCAN. Если DME не отвечает — попробуйте включить DTR и переподключиться.

  
Автосохранение в GitHub

  
Чтобы не набирать токен на магнитоле: откройте на ней ссылку …/m54-live/#gh=Greemq/M54-logs,github_pat_… — настройки сохранятся и исчезнут из адреса. Ссылку удобно собрать на телефоне и отправить в Chrome магнитолы («Отправить на устройства» / «Недавние вкладки»).

  
Создайте репозиторий (например m54-logs, можно приватный) и токен: GitHub → Settings → Developer settings → Fine-grained tokens → только этот репозиторий, Permissions → Contents: Read and write. Токен хранится только в этом браузере.

  
  
  
  
  

  
DS2-консоль (другие блоки)

  
Чтобы вывести скорости колёс (DSC), климат (IHKA) и температуру АКПП (EGS), нужно найти раскладку их ответов. Выберите блок, нажмите «Опросить» — ниже сырые байты. Байты, которые меняются при вращении колёс / смене температуры — и есть нужные. Если включить «постоянно» и вести запись лога, байты пишутся в отдельный файл …_ds2_XX.csv рядом с логом и уходят в GitHub — раскладку можно найти по нему.
